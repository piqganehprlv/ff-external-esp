# Security Policy

This repository is an **educational FreeFire external cheat research project**.
It is not affiliated with Garena or FreeFire.

## Scope

- Reports about memory-safety issues in the injector/overlay code are welcome.
- Reports about the cheat being detected by anti-cheat are **out of scope** —
  this project is for offline/emulator educational study only.

## Reporting

Open a private security advisory on GitHub. Do not file public issues for
memory-corruption bugs in `src/core/memory_reader.py` or `src/core/injector.py`.

## Disclaimer

Use of this software violates the FreeFire Terms of Service. The maintainers
accept no responsibility for bans, account loss, or legal consequences.
Use at your own risk, in emulators or single-player test environments only.
