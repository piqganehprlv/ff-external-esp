How it works

Three steps from download to overlay

No installers, no dependencies. The whole setup takes under a minute.

1

Download & extract

Grab the latest build from the download page, then extract the archive into any folder. Everything ships as a single self-contained executable — no runtime installs, no DLL bundles.

2

Launch the overlay

Run ff-external-esp.exe as administrator so the overlay can attach to the game window. The transparent render window appears on top of the desktop, ready to draw.

3

Toggle your modules

Use the in-overlay menu to switch on player boxes, skeleton ESP, distance readout or item glow. Settings persist between sessions in a local config file.

FAQ

Questions before you download

Straight answers about the project, its purpose and its requirements.

Is ff-external-esp really free?

Yes. The project is free and fully open source. The source is published on the repository, and the compiled build is available from the download page at no cost. There are no paid tiers, keys or subscriptions.

Which Windows versions are supported?

The build targets Windows 10 and Windows 11, 64-bit. It uses standard Win32 overlay APIs and DirectX rendering, so no extra Visual C++ redistributables or .NET runtime are required beyond what ships with Windows.

Why does it say "educational purpose only"?

This repository exists as a learning resource for external overlay rendering in C++. It demonstrates window compositing, memory reading patterns and drawing ESP primitives. It is not distributed for competitive play, and using it in live matches is against the game's terms of service.

Does it use an injector or modify game files?

No. The overlay is entirely external — it never injects a DLL into the game process and never writes to game files on disk. It reads data externally and renders its own transparent window on top of the desktop, which is exactly the technique this project is meant to teach.
